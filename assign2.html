# Assignment 2 – Setup Proof (VS Code, Node.js, Live Server) Objective To install and verify Visual Studio Code, Node.js, and the Live Server extension for web development. Step 1: Install Visual Studio Code (VS Code) Open your browser. Visit the official VS Code website: Visual Studio Code Click on Download for Windows. Install VS Code on your computer. Open VS Code after installation. Take a screenshot showing VS Code running. Proof: Screenshot of VS Code. Step 2: Install Node.js Open your browser. Visit the official Node.js website: Node.js Download the LTS version. Run the installer. Follow the installation instructions and complete the setup. Open VS Code. Open the terminal using `Ctrl + `` (backtick). Type the following command: node -v Press Enter. If a version number appears (for example, v22.x.x), Node.js is successfully installed. Proof: Screenshot showing the node -v command and its output. Step 3: Install Live Server Extension Open VS Code. Click on the Extensions icon on the left sidebar. Search for Live Server. Find the Live Server extension by Ritwick Dey. Click on Install. Wait for the installation to complete. Proof: Screenshot showing the Live Server extension installed.
